# No_Show_Guard
### AI-Powered No-Show Prediction and Analysis Project

## 1. Project Overview
No_Show_Guard is an AI-powered project designed to analyze appointment data and support the prediction and analysis of appointment no-shows.

The project uses Python, data analysis, machine learning, and Generative AI components.

## 2. Project Objectives
- Analyze appointment and clinic data.
- Identify patterns related to missed appointments.
- Perform data cleaning and preprocessing.
- Develop machine learning-based analysis.
- Explore AI-powered insights for appointment management.

## 3. Dataset Description
The project includes the following datasets:

- `appointment.csv`
- `clinic.csv`
- `followup_notes.csv`

Additional data and analysis files are included in the project repository.

## 4. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Generative AI
- PyDantic

## 5. Project Files
- `task_1_1.py` to `task_1_6.py` – Python task files
- `part3_ml.py` – Machine Learning component
- `part4_genai.py` – Generative AI component
- `load_data.sql` – SQL data loading script
- `requirements.txt` – Python dependencies
- `Data/` – Dataset folder

## 6. Installation

Clone the repository:

```bash
git clone https://github.com/avinashpathak1996/No_Show_Guard.git
```

Navigate to the project directory:

```bash
cd No_Show_Guard
```

Install dependencies:

```bash
pip install -r requirements.txt
```
